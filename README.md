# Sistema de Agendamento para Salão

Sistema desenvolvido em Java para gerenciamento de agendamentos de um salão de beleza, com validação de profissionais, horários e cadastro dos clientes em banco de dados MySQL.

## Funcionalidades

- Cadastro e listagem de profissionais.
- Consulta de serviços disponíveis.
- Validação do horário de atendimento.
- Verificação do profissional responsável pelo serviço.
- Cadastro do cliente no MySQL após agendamento válido.
- Uso de Streams e Optional para tratamento das buscas.
- Persistência de dados utilizando JDBC.

## Tecnologias

- Java
- Java Streams API
- Optional
- JDBC
- MySQL
- MySQL Connector/J
